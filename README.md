## 2. 字体

参考站用三套商用字体（Untitled Sans / Tronica Mono / AtHauss Mono），本页用开源的 **Inter** 和 **Space Mono** 近似替代，字号字距完全对齐。

| 层级 | 字号 | 字重 | 字距 | 行高 | 字体 |
| --- | --- | --- | --- | --- | --- |
| 首屏大标题 | 42 → 80 → 120 → **140px**（断点 700/1024/1200） | 400 | **-0.04em** | 0.88 | Inter |
| 标题里的关键词 | 同左 | 400 | 0 | — | Space Mono |
| 分区陈述句 | `clamp(28px, 4.4vw, 56px)` | 400 | -0.03em | 0.92 | Inter |
| 作品标题 | `clamp(26px, 3.2vw, 44px)` | 400 | -0.03em | 0.95 | Inter |
| 联系区大标题 | `clamp(32px, 5.2vw, 64px)` | 400 | -0.03em | 0.9 | Inter |
| 正文 / 描述 | 17px | 400 | 0 | 1.5 | Inter |
| 副标题 | **13px**（1024 起 16px） | **500** | 0.04em | 1.45 | Space Mono |
| 导航 / 编号 / 标签 | **11px** | **500** | **0.12em** | — | Space Mono |
| 按钮 | **13px**（1024 起） | **500** | **0.1em** | — | Space Mono |

三条关键规则（都是参考站原文）：

1. **所有标题字重都是 400**，页面里唯一的重字是按钮和导航的 500。
2. **大标题用负字距收紧**（-0.04em），**小标签用宽字距放开**（0.1–0.12em），全大写。
3. **关键词切成等宽体**做强调 —— 参考站是 `Commerce,<span>Elevated</span>`，本页是 `Front<em>end</em>` 和中英混排的标题。

## 交互与动效

参考站的入场效果是 **上移 100px + 淡入**，位移 1.2s、缓动 `cubic-bezier(.43,.195,.02,1)`、错峰 delay。本页用同样的参数，通过 IntersectionObserver 触发（首屏元素加载即入场，其余进入视口时触发）：

| 动效 | 参数 |
| --- | --- |
| 元素入场 | `translateY(100px) → 0` + `opacity 0 → 1`，1.2s `cubic-bezier(.43,.195,.02,1)` |
| 错峰 | `delay-1` .25s / `delay-2` .4s / `delay-3` .6s |
| 导航下划线 | `width 0 → 100%`，.6s `cubic-bezier(.8,0,0,1)` |
| 导航方块 | `scale(0) → scale(1)`，1s |
| 顶栏按钮 hover | 底色 → `#EE344A`，.4s |
| 作品图 hover | 遮罩 `.32 → .05` + 放大 1.03 |
| logo hover | 旋转 -90°，.6s |

> 参考站的滚动是 Lenis + GSAP 的整页滚动劫持（`height: 500vh~760vh` + `position: sticky` + 负 margin，配合 WebGL 粒子、3D 卡片轨道）。那套是定制营销页的写法，放在作业作品集里会让正常滚动变难用，所以本页只保留了它的**视觉语言**（配色、字体层级、零圆角、毛玻璃、网格）和**入场动效参数**，没有搬滚动劫持。另外 `prefers-reduced-motion: reduce` 下入场动画会自动关闭。
